# TASK-044-T1 评分口径

场景各 12 题。账号 `owner` 拥有 `t1-harbor/US`，`other` 拥有 `t1-outlet/US`。`questions.json` 逐题冻结题面、绑定范围、生效版本、期望行为和原文位置。每个 `required` 元素表示一个独立必要事实，同组原文是可互换的证据。偏移使用原始 UTF-8 文件解码后的 Unicode 字符索引，区间左闭右开。缺件例同时保留仍可读的原文与完整例中被移除的原文。无答案例标注同术语的干扰段落。所有商品和资料均为本任务构造的合成样本。资料合同沿用生产的规则格式，按已知商品事实配置，没有根据模型输出调整。

- **可答**。每个必要事实单独计前 5 和前 20 命中。至少需要同一分块完整覆盖带标注的位置及摘录。多证据找齐以题为单位。最终完整引用要求所有必要事实获引，额外引用必须在该题允许的证据内，且 SSE 报明当前 SKU 和版本。答复中的非引用内容须与冻结事实一致。当前 SSE 为固定的原文呈现模板，校验头部、原文正文和引用格式即可覆盖其最终事实输出。各有可答题的场景各自达到 90% 的前 20 必要原文命中率和最终完整引用率。
- **待选 SKU**。未提交 SKU 时应请用户选择或指定 SKU，候选、证据链接和事实结论均须为空。SSE 使用仅含店铺和站点的命令前缀，题面另起一行。候选名称在 `scope_choices` 中给出。

- **无答案**。明确表示资料不足，禁止以干扰资料作答或附来源。允许复述缺失的事实或适用条件。
