# StorePilot 远程演示部署草案

远程演示使用独立实例、账号和数据目录。进入演示的来宾只访问合成商品或已导入的公开数据，测试商品的改动经过人工批准。可先用本机回环跑通，再按下面的顺序验收外部访问。

已在 Windows 浏览器验收工作台，并在本机 WSL2 验收封闭容器。本文涉及的云环境、代理和访客访问需按实际部署环境验收。[工作台实拍](SHOWCASE.md)

## 1. 在云端启动独立实例

1. 在独立工作目录检出选定发布版本。使用 `APP_STARTUP_MODE=business`，将 `DIAGNOSIS_SANDBOX_DB_PATH` 指向演示 SQLite 的绝对路径。提前从已准备的合成数据恢复，核对分配给来宾的账号、店铺、SKU 和计划登记。保留初始快照以便重置。
2. 在服务端配置独立的 `JWT_SECRET`、演示用模型密钥和独立 `RAG_DB_PATH`。演示真实 GLM 时用 `LLM_PROVIDER=glm` 和 `GLM_API_KEY`。真实 RAG 使用锁定的 BGE 权重。Amazon 授权配置留空，GPU 重排保持关闭。依赖和模型缓存的准备步骤见 [部署文档](../DEPLOY.md)。
3. 给来宾分配独立普通账号。对从本地演示库恢复的实例，停用或更换默认凭据，重置后复核一次。
4. 启动单 Web 并监听回环地址，再从该主机核对就绪探针和测试登录。

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip --isolated install --require-hashes -r locks/bge.txt
.venv/bin/python -m uvicorn fast_server:app --host 127.0.0.1 --port 5010 --workers 1
```

## 2. 配置 HTTPS 和访客范围

将受访客身份验证保护的 HTTPS 入口代理至 `127.0.0.1:5010`。访客经入口验证后，再使用应用账号登录。代理需要及时转发 SSE 进度和正文。按下节确认浏览器在任务结束前收到事件，并检查访客之间的记录隔离。

## 3. 从外网做一次走查再分享

- 用手机流量或另一条外网，在无痕窗口打开演示域名。验证未获准邮箱不能进入、允许邮箱能登录、页面资源和示例会话可读。
- 发一条销量问题，再发一条已验过的协作复核问题。浏览器应在任务结束前收到 `/api/chat/stream` 的首帧和进度，界面应随 SSE 显示取证与等待，最后显示完成。记录外网实测的首帧时间和一次完整运行时长。
- 用演示账号批准一项本地测试商品改动。浏览器批准后应另发 GET，读回实际版本和回执。刷新后重新打开原答案，应看到同一个回执。从另一演示会话核对记录未串入。
- 验收后向来宾提供演示地址和其专用账号，结束后撤销访客访问。
